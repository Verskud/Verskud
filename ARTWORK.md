# Artwork and assets

The banner is original AI-generated fan artwork created with the built-in imagegen tool. It is inspired by Arcane from **Arknights: Endfield**, using [the official operator portrait](https://endfield.gryphline.com/en-us/operator) as an identity reference. The character belongs to HYPERGRYPH / GRYPHLINE. This profile is unofficial and is not affiliated with the game.

The language icons use [Simple Icons](https://github.com/simple-icons/simple-icons), licensed under CC0. Layouts and the other vector graphics were made for this profile.

The profile uses local static image assets and no tracking images or third-party statistics services.
